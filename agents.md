# Proyecto: Web Informática UNSXX Refactor

**Reglas Operativas del Agente IA:**
- Las reglas innegociables de arquitectura y seguridad están en `docs/constitution.md`. Léelas siempre.
- La metodología de trabajo es Spec-Driven Development (SDD).
- No escribas código sin antes tener una especificación (`specs/spec-XX.md`) y un plan de tareas aprobado.
- Genera código limpio, estructurado y documentado en español. Nombres de variables y funciones en inglés.
